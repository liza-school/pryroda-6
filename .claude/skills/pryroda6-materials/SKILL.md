# Матеріали з «Пізнаємо природу», 6 клас

Матеріал робиться для дитини, яка вчиться в Черкасах і складатиме уроки за підручником
Д. Д. Біди «Пізнаємо природу» (К.: Видавничий дім «Освіта», 2023, інтегрований курс).
PDF лежить у корені репозиторію (`Piznaemo-prirodu-6-kl.pdf`, у git не входить).

Курс зроблено за зразком «Географії 6 клас» (`../Географія 6 клас`, github.com/liza-school/geografia-6):
той самий рушій, ті самі типи блоків, ті самі закони. Якщо правило тут не описане — дивись
`.claude/skills/geo6-materials/SKILL.md` там.

## Пʼять законів

1. **Підручник — база.** Терміни, числа, означення й формулювання беруться з підручника,
   а не з памʼяті й не з інтернету. Спершу витягти текст параграфа з PDF, потім писати.
2. **Нічого головного не втрачено.** Матеріал покриває ВЕСЬ обовʼязковий зміст параграфа
   (таблиця нижче). Скорочувати можна подачу, але не зміст.
3. **Але й не перевантажуємо.** Дитині 11 років. Другорядне — у згортку (`fold`) або геть.
4. **Шість наскрізних врізок у кожному параграфі:** `cherkasy`, `ukraine`, `potter`
   (мовою Гаррі Поттера + обовʼязкове речення, чим справжній світ відрізняється від чарів),
   `horse` (стайня, манеж, електропастух), `life` (3–4 речі, які можна перевірити самій),
   `game` (Brawl Stars, Minecraft + чим справжній світ відрізняється). Плюс хоча б одне питання
   про Черкащину або Україну.
5. **Завжди прості приклади.** Кожне означення має поруч приклад із життя 11-річної дитини:
   кухня, двір, стайня, Дніпро й Кременчуцьке водосховище, телефон, тролейбус.

## Мова: спрощувати можна, спотворювати — ні

* **Не змінюємо:** термін, число, одиницю, назву («упорядкований рух заряджених частинок»).
* **Змінюємо вільно:** пояснення, довгі речення, канцелярит.
* Книжкове означення лишається в полі `book` таблиці термінів — його спитає вчителька.

## Безпека — окремий закон для фізики

Параграфи про електрику, тепло, світло й хімію містять досліди. Кожен дослід, який дитина може
повторити вдома, має поруч межу безпеки: що можна лише з дорослими (ніж, гаряча вода, вогонь),
чого не можна ніколи (розетка, оголені дроти, батарейки-«таблетки» в рот). Якщо підручник
пропонує дослід без застереження — додати застереження, а не прибирати дослід.

## Помилки й застарілі місця підручника — червоним

Блок `errata`: **У підручнику** (цитата + сторінка), **Насправді**, **На уроці кажи**.
Кожен запис також іде в `course/tools/errata.json`; харнес перевіряє, що блоків на сторінці
не менше, ніж записів.

Підручник 2023 року, тому «застаріло» — теж `errata`, із поясненням, що тоді було правильно.

Уже знайдені:

| § | Сторінка | У підручнику | Насправді |
|---|----------|--------------|-----------|
| 7 | 33 | блискавка розігріває повітря «майже до 10 000 °С» | на мить ~30 000 °С, уп'ятеро гарячіше за поверхню Сонця |
| 8 | 36 | прилади працюють від 220 В | з 1 липня 2025 р. стандарт в Україні — 230 В (207–253 В) |
| 9 | 41 | напругу знижують до 220 В | теж 230 В з 2025 року |

Якщо підручник не помиляється, а спрощує (джерела струму «мають полюси + і −», хоча генератор
дає змінний струм; «провідники тепла = провідники електрики», хоча алмаз — виняток) —
це не `errata`, а згортка «Підручник недоговорює» з рядком курсивом: на уроці відповідай
за підручником.

## Що саме треба витягти з параграфа

Номер сторінки PDF = номер сторінки книжки + 2 (стор. 31 — це PDF 33).

```bash
PYTHONIOENCODING=utf-8 python - <<'PY'
import fitz
d = fitz.open("Piznaemo-prirodu-6-kl.pdf")
for pno in range(32, 43):                 # 0-based: PDF 33–43 = стор. 31–41
    print("=== PDF", pno + 1, "===")
    print(d[pno].get_text())
PY
```

Малюнки краще рендерити шматком сторінки, а не тягнути з `images`: багато схем векторні
(мал. 25, 31, 35), а номери «1», «2», «3» на фото — накладені поверх.

```python
pix = fitz.open(PDF)[pno].get_pixmap(matrix=fitz.Matrix(3, 3), clip=fitz.Rect(x0, y0, x1, y1))
# далі PIL: .convert("RGB"), thumbnail((1000, 1000)), JPEG q86
```

Спершу відрендерити всю сторінку в PNG і подивитися — так видно, де закінчується малюнок
і чи не залізла в кадр частина підпису. Підпис: «Мал. N. Назва (підручник, стор. X)».

Обовʼязковий зміст параграфа в цьому підручнику:

| Що | Де в підручнику | Куди в матеріал |
|----|-----------------|-----------------|
| Вступ курсивом під заголовком § | початок | перший `text`, курсивом |
| Пронумеровані підзаголовки (1, 2, 3, 4) | тіло параграфа | розділи конспекту, жоден не пропущено |
| Означення в рамочці з олівцем, терміни жирним курсивом | по тексту | таблиця `terms` + текст |
| Числа й одиниці (В, кВ, °С, м) | по тексту | конспект + щонайменше одне питання |
| Підписи до малюнків | мал. N | текст або підпис `image` |
| Дослід (колба) | врізки | `note` або `life`, з безпекою |
| Питання на полях (знак «?») | врізки | `fold` з відповіддю або питання тесту |
| «Це цікаво» | врізки | `text` або `fold` |
| Цифрові матеріали (відео, «Наукові суперечки») | QR-врізки | згадка в `fold` |
| «Коротко про головне» | кінець | `summary` — усі пункти дослівно за змістом |
| «Запитання / Завдання / Дослідження» | кінець | `fold` з підказками + питання |

## Формат

Курс лежить у `course/`, будова й типи блоків — у `course/README.md`.
Урок — це дані (`COURSE.addLesson`), верстку писати не треба.

Порядок блоків: конспект (`text`) з малюнками → `errata` біля місця помилки → `terms` →
`summary` → `cherkasy` → `ukraine` → `potter` → `horse` → `life` → `game` → `fold` → питання.

Малюнок, менший за 600 px або вертикальний, — з полем `max` (ширина в px), інакше він
розтягнеться на всю сторінку й розмиється. Два малюнки дуже різних пропорцій у `gallery`
не ставити.

## Перевірка перед тим, як віддавати дитині

```bash
cd course && node tools/check.js
```

Харнес перевіряє рендер сторінок, шість врізок, кількість і типи питань, зарахування відповідей,
прогрес, малюнки, реєстр помилок і покриття з `tools/coverage.json`. Додаючи параграф — допиши
його в `LESSONS` у `tools/check.js`, в `index.html` і обовʼязковий зміст у `coverage.json`
(малими літерами, коренями слів: «електризаці», «напруг»).
