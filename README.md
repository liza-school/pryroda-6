# Пізнаємо природу, 6 клас

Інтерактивний конспект для Лізи за підручником Д. Д. Біди «Пізнаємо природу»
(Київ: Видавничий дім «Освіта», 2023). Параграфи 7–9 (електрика) з підсумковим тестом
і § 10 (світло й тінь) — 44 завдання з автоперевіркою.

Онлайн: https://liza-school.github.io/pryroda-6/

Локально — подвійний клік по `index.html`. Ні сервера, ні збірки, ні інтернету.

* [course/README.md](course/README.md) — що всередині, типи блоків, як додати параграф
* [.claude/skills/pryroda6-materials/SKILL.md](.claude/skills/pryroda6-materials/SKILL.md) — правила,
  за якими робиться матеріал

Зроблено за зразком [«Географії 6 клас»](https://github.com/liza-school/geografia-6): той самий рушій,
ті самі блоки. PDF підручника в репозиторій не входить — лежить локально поруч із цією текою.

Перевірка перед тим, як віддавати: `cd course && node tools/check.js`
